# 🖤 Эликса — Помощница Гильдмастера

Суккуб-бухгалтер гильдии воров и наёмников.

## 🚀 Как запустить на другом ПК

### Шаг 1: Установи Node.js (если ещё не установлен)
Скачай с https://nodejs.org/ (версия LTS)

### Шаг 2: Скачай проект
```bash
git clone https://github.com/ТВОЙ-ЛОГИН/ИМЯ-РЕПО.git
cd ИМЯ-РЕПО
```

### Шаг 3: Запусти
**Windows:**
```
run.bat
```

**Mac/Linux:**
```bash
chmod +x run.sh
./run.sh
```

### Шаг 4: Готово!
Приложение откроется в браузере автоматически.

## 💾 Перенос данных

### Экспорт (со старого ПК):
1. Открой приложение
2. Нажми **📤 Экспорт**
3. Сохранится JSON файл со всеми забегами

### Импорт (на новом ПК):
1. Открой приложение
2. Нажми **📥 Импорт**
3. Выбери JSON файл
4. Все данные восстановятся!

## 📁 Структура проекта

```
├── src/              # Исходный код
├── dist/             # Собранное приложение (после сборки)
├── run.bat           # Запуск для Windows
├── run.sh            # Запуск для Mac/Linux
└── package.json      # Зависимости
```

## 🔧 Ручная сборка (если нужно)

```bash
npm install
npm run build
```

После этого папка `dist/` будет содержать готовое приложение.

## 💡 Советы

- Данные хранятся в localStorage браузера
- При переносе на другой ПК не забудь экспортировать данные
- Можно открыть `dist/index.html` напрямую в браузере без запуска скрипта
